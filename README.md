# Pinkie IT — Landing Page Jasa IT (Next.js + Tailwind)

## Menjalankan
```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Mengubah konten
Semua teks, harga, proyek, FAQ, nomor WhatsApp, dan email ada di `lib/data.js`.
Warna tema ada di `tailwind.config.js` (palet `kitty`).

## Deploy gratis
Push ke GitHub, lalu import repo di https://vercel.com (framework otomatis terdeteksi Next.js).
